# Quality.Noted

**Catch problems before release, prep for wherever you ship (Mac App Store, Homebrew or direct download), and know when your Mac app is ready.**

Release-readiness QA audits for Mac apps, run with your own Claude Code. Follows the seven ISTQB principles of software testing.

Quality.Noted audits your Mac app with Claude Code and gives you a readiness score out of 100, findings ranked worst first, one prompt to fix them, and a re-check that confirms your fixes in minutes.

- **Website:** https://quality.notedsuite.app
- **Help:** https://quality.notedsuite.app/help
- **Support:** https://notedsuite.app/support

## Download

- **Direct:** the latest build is under [Releases](https://github.com/NotedSuiteApps/Quality.Noted/releases/latest)
- **Homebrew:**
  ```
  brew install --cask notedsuiteapps/tap/quality-noted
  ```

Builds are signed with a Developer ID certificate, notarized by Apple, and update through Sparkle.

## Requirements

- macOS 14 Sonoma or later, on Apple silicon
- [Claude Code](https://claude.com/claude-code), signed in, on your own Claude plan or API key
