# Quality.Noted

Release-readiness QA audits for Mac apps, run by your own Claude Code.

Quality.Noted audits your Mac app's source code with Claude Code and tells you whether it's ready to release, on the Mac App Store, through Homebrew or as a direct download. You get a readiness score out of 100, findings ranked worst first, one prompt to fix them all, and a re-check that confirms your fixes in minutes.

- **Website:** https://quality.notedsuite.app
- **Help:** https://quality.notedsuite.app/help
- **Support:** https://notedsuite.app/support

## Download

Downloads appear under [Releases](https://github.com/NotedSuiteApps/Quality.Noted/releases) with the first release. Release builds are signed with a Developer ID certificate and notarized by Apple, and update themselves through Sparkle.

## Requirements

- macOS 14 Sonoma or later, on Apple silicon
- [Claude Code](https://claude.com/claude-code), signed in, on a Claude subscription or API key

## About this repository

This repository hosts Quality.Noted's release downloads and its update feed. The source code is not public.

Quality.Noted is free to try; the full version is a one-time purchase.
